# 기계 귀 — 재는 것 · 문턱 · 까닭 (11-14)

`npm run test:ear`(1~2분 · `npm test`에는 넣지 않음)가 소리를 OfflineAudioContext(48000Hz)로 그려 숫자로 잰다(`tests/ear.lab.js`).
잰 값 전부와 단언 목록 `checks: [{ id, ok, note }]`가 `tests/ear.report.json`에 남고, `node tools/bar.mjs`가 「소리(기계)」 %로 읽는다.

**문턱은 모두 우리가 정한 값이다.** 사람 귀로 맞춘 것이 아니다 — 합성음이 그 악기처럼 들리는지, 작은 차이가 아이 귀에 들리는지는 사람이 들어야 안다.

| 단언 id | 문턱 | 까닭 |
|---|---|---|
| `pitch:<악기>` | 칸이 쓰는 음 모두 ±10센트 | 어긋나면 실패(종료 코드 1) |
| `sound:<악기>` · `sound:drum:<북>` | RMS −60dBFS 위 | 소리가 안 나면 실패 |
| `clip:<자리>` | 피크 0.99 밑 | 깨지면 실패 |
| `level:cells` | 칸이 쓰는 악기 사이 A 가중 크기 차 4dB 안(솔4 · vel 0.6 · 0.8초) | 악기만 바꿨는데 크기가 달라지면 '음색'을 '세기'로 듣는다 — 보정은 `audio.js` `LEVEL` |
| `vel:<칸>:<악기>` | 세기 짝 차 6dB(A) 위 · 비틀기 '크게'(so6 · hy1)는 8dB(A) 위 | '크게'가 들려야 함정이 함정이 된다 |
| `click:<악기>` | 시작 · 끝의 둘째 차이가 몸통의 4배 · 피크의 1% 넘으면 걸림 — 단 첫 20ms 가장 큰 값의 절반까지 **0.25ms 넘게 걸려 오르면** 타격 첫머리로 봄 | 말렛 · 줄 뜯는 소리는 본디 뾰족하다. 디지털 딸깍은 0에서 한 표본 만에 뛰는 계단이다(단단한 채가 닿는 때 0.5~1ms보다 훨씬 빠름). 뜯는 소리 셋(피치카토 · 하프 · 가야금)은 첫 표본이 계단이어서 2ms 오름을 넣었다 |
| `timing:<악기>` | 첫 소리 어긋남 1ms 안 · 피크 절반까지 50ms 안(현악 합주 · 합창은 80ms 안) | 차오름이 느리면 박보다 늦게 들린다. 두 악기는 짧은 음에 쓰는 칸이 있어(sem1 · ri4 · so3 · ga1 · ga2 · ga4 · so4) 음 길이의 1/10로 차오르게 함 |
| `timbre:so6:<a>-<b>` | 가까운 짝 거리가 모두 다른 짝 가장 가까운 것보다 작음 | 음색 거리 = 무게중심 · 차오름 · 0.5초 뒤 크기 · 홀짝 배음 넷을 표준화한 거리 |
| `cell:sem1:*` | 큰 쪽 6dB(A) 위 | |
| `cell:so3:*` | 들린 길이(−30dB 위 · 울림 꼬리 포함)가 '긴 소리' 문턱 0.6초의 맞는 쪽 | |
| `cell:so5:*` | 답이 아닌 둘은 ±10센트 · ±0.1초 · ±3dB(A) · 크기 답은 6dB(A) 위 | 높이만 바꾼 짝이 크기도 달라지면 답이 둘 | 
| `cell:ppa1:*` | 기계 귀가 찾은 소리 시작 수 = 음 수 | |
| `cell:hwa1:soft*` | 아래 낮은 소리의 250Hz 위 에너지 50% 위 | 작은 스피커(크롬북)는 250Hz 밑을 거의 못 낸다는 **가정** — 기기에서 잰 값이 아니다(크롬북 스피커로 재 본 적 없음) |
| `cell:so6:loud*` · `cell:hy1:loud*` | 8dB(A) 위 | |
| `cell:so6:pitch*` | 크기 차 ±3dB(A) 안 | 높이만 바꿨는데 크기가 달라지지 않게 |

- `audio.js` `LEVEL` — 악기마다 크기 곱(리코더 0.53 … 피치카토 2.2) · 플루트 · 리코더 · 바이올린은 옥타브당 −4.8dB 기울기(높을수록 귀에 커지는 만큼).
- 뜯는 소리 셋 2ms 오름 · 현악 합주 · 합창 차오름 = 음 길이 × 0.1(0.03~0.14초).
- 칸: so3 발전 짧은 소리 0.35 → 0.3초 · so6 작게 0.35 → 0.25 · 짝 다시 고름 · hy1 작게 · 크게 0.4 · 0.85 → 0.28 · 0.9 · hwa1 낮은 솔(55) → 레(62).

## 남은 것
- 크롬북 스피커 저음 한계(250Hz)는 가정이다 — 실제 기기에서 재 보지 않았다.
- 1단계 팀의 마지막 손질(부풂 북 잴 구간 1.55초 · 홀짝 비 ±30dB 자름)은 `tests/ear.lab.js`에 그대로 있다.
- 주제곡을 소리 길 크기 1로 다 열면 피크 0.97(실제 배경 음악 크기 0.38에서는 0.64) — 문턱 안이지만 여유가 적다.
- 하프 · 가야금 · 피치카토는 줄 버퍼가 잡음에서 나와 판마다 크기가 ±1dB쯤 다르다(시험은 씨앗을 고정해 잰다).
