# 방 번호 다같이 명세 v1 — '오늘만' 방(기록 남기지 않음 · 계획서 '선생님과 다같이' TV + 아이 기기)

선생님이 TV에서 방을 열면 네 자리 방 번호가 크게 뜬다. 아이들은 자기 기기에서 방 번호 · 출석 번호 · 짝꿍 친구(동물)를 고르고 들어온다. 선생님이 TV에서 놀이와 단계(보기 · 연습 · 확인 게임)를 바꾸면 **아이 기기 화면이 2초 안에** 그 놀이 · 단계로 바뀐다. 아이가 확인 게임을 끝내면 결과(별 · 맞힌 수)가 방에 모이고, TV에는 **'끝낸 아이 n / m' 반 막대**만 뜬다(번호 · 아이별 별 X — v3 · X6). 번호와 별은 선생님 '복사'(클립보드)로만 나간다. 이름은 어디에도 없다.

## 서버(만들어 둠)
- Firebase 프로젝트 `music-nori-class` · Realtime Database `https://music-nori-class-default-rtdb.asia-southeast1.firebasedatabase.app` (무료 요금제 · REST만 · 로그인 없음 · 스트림 연결 X → 2초 확인)
- 규칙 `database.rules.json`(올려 둠) · 진짜 DB 시험 `node tests/room.rules.cjs`(14개 통과 · 시험 방 0000~0999)
- 자료 모양
  - `rooms/{방 4자리}/own` = `{ tok, at }` — 선생님 열쇠(읽기 X · 12시간 지나면 다른 사람이 다시 잡을 수 있음) · `at`은 `{".sv":"timestamp"}`
  - `rooms/{방}/t` = `{ tok, pub: { cell, phase, at } }` — 열쇠가 맞아야 쓰기 · 아이는 `rooms/{방}/t/pub`만 읽음. phase = `wait | show | follow | game | done`(wait일 때 cell은 아무 칸 이름이나 — 예 'so3')
  - `rooms/{방}/res/{기기 8~16자 a-z0-9}` = `{ a: 친구 번호 0~4, no: 출석 번호 1~40, c: 칸, s: 별 0~3, k: 맞힌 수, n: 전체 수, at }` — 들어올 때 s=k=n=0으로 한 번 써서 '들어왔음'을 알림(c는 지금 pub.cell) · 확인 게임 끝나면 덮어씀
- 방 번호는 1000~9999 중 무작위 · 잡기(PUT own)가 실패하면 다른 번호로 다시(8번까지)

## 화면
1. **선생님 — TV로 다같이(`screens/tvpick.js`)**: 위에 '방 열기' 단추. 열면 머리띠 오른쪽에 '방 1234'(크게)와 '들어온 기기 n대'. 방 정보는 이 기기에 저장(`lsSet('troom', { room, tok, at })` — 12시간 안이면 다시 열어도 같은 방) · '방 닫기'(이 기기에서만 잊음)
2. **선생님 — TV 칸(`screens/cell.js` TV 모드)**: 방이 열려 있으면 단계가 바뀔 때마다 `t.pub = { cell, phase }`를 씀(보기 · 연습 · 확인 게임 · 결과 뒤 done). TV 안내 줄 옆(또는 아래 띠 왼쪽)에 **모인 결과 띠**: 보기 · 연습은 "들어온 기기 12대", 확인 게임 · 결과는 "끝낸 아이 8 / 12" + 반 막대 + "아직 4명"(번호 · 별 X — 아래 v3) — 확인 게임 · 결과 단계에서 2초마다 `res`를 읽어 이 칸(c) · 이번 단계 시작 뒤(at) 결과만. 결과 카드가 뜬 뒤에도 띠는 남아 들어오는 결과를 계속 보여 줌
3. **아이 — 방 들어가기(`screens/join.js` 새 화면 · #/join)**: 처음 화면 머리띠 오른쪽에 '방 번호' 단추(톱니 옆) → 큰 숫자 판(0~9 · 지우기)으로 방 번호 4자리 → 출석 번호(1~30 큰 단추 판) → 짝꿍 친구 다섯 중 하나(friendImg face) → '들어가기' → 대기 화면 "선생님이 놀이를 고르면 바로 열려요"(짝꿍 친구 그림 · 방 번호 · 나가기). 방이 없거나 12시간 지난 방이면 "방 번호를 다시 봐요"
4. **아이 — 방에 있는 동안(`main.js` 전체)**: 2초마다 `t/pub`를 읽어 바뀌면 그 놀이 · 단계로 이동(`#/cell/<칸>/<단계>` · 리1은 `#/tap`) · wait면 대기 화면. 머리띠 오른쪽에 '방 1234' 칩(누르면 나가기 확인). 탭이 숨겨져 있으면(visibilityState hidden) 확인을 멈춤
5. **아이 — 칸 화면(`screens/cell.js`)**: `args[1]`로 시작 단계를 받음(show · follow · game). 방에 있고 이 칸이 선생님 칸이면: 확인 게임 끝(finish)에 결과를 `res/{기기}`로 보냄 · 결과 아래 띠는 '다음 놀이' 대신 "선생님을 기다려요"(한 번 더는 그대로) · 선생님이 단계를 바꾸면 따라감. 아이 기기 진행(별)은 그대로 저장
6. **소리**: 아이 기기는 그대로(이어폰 있으면 각자). '아이 기기 작게' 스위치는 다음 판

## v2 — 소리는 TV 하나 · 답은 각자(11-08 토론 T1 · 교사 승인 '추천으로')
교실 크롬북 반은 소리가 안 나고 반은 이어폰이 없다(현장 교사 공격) → 방이 열린 TV에서 **TVS 칸(지금 소4)**의 확인 게임을 열면:
- TV가 `t.pub`에 **`sd`(판 씨앗 숫자)**를 함께 씀. 아이 기기는 그 판을 읽고 같은 씨앗으로 같은 판 차례(stageShuffle)를 만든다.
- **시간표**: 첫 판 = `pub.at + 5000`(서버 ms) · 판마다 5.4초(두 소리 0.3초 뒤 · 둘째 소리부터 고르기 · 둘째 소리 끝 + 3.5초에 닫힘). 아무도 기다리지 않음 · 늦게 받은 판은 '시간 지남'.
- **서버 시각 맞추기**: TV는 pub 쓰기 응답의 `at`, 아이는 자기 결과 칸에 `{at: 서버시각}`을 PATCH 세 번(가장 빠른 왕복)으로 `off = 서버 − 이 기기`를 어림. 같은 맥 시험에서 두 기기 시간표 어긋남 3ms · 왕복 160ms.
- **소리는 TV에서만**. 아이 기기는 답 단추만 — 고르면 '답했어요'(고른 쪽을 가림 · 옆 친구 따라 하기 X) · 판이 끝나면 다 같이 맞는 자리.
- 아이 기기는 판이 끝날 때마다 **`res.ans`(판마다 U · D · x 글자)**를 PATCH(그동안 s = k = n = 0 → TV 띠가 '끝낸 아이'로 세지 않음) · 끝에 결과와 함께 다시 씀. 아이 기록 hist에 `r: 'tvs'`.
- TV는 답 자리에 **비율 막대**(나무 쪽 · 연못 쪽 · 수 X · 누가 골랐는지 X)와 맞는 쪽 테두리 · 끝나면 '반 전체 — 판마다 절반 넘게 맞힌 판'(반 별).
- 규칙(올림): `pub.sd` 0~4294967295 숫자 · `res.ans` `/^[A-Za-z0-9.]{0,24}$/` · 진짜 DB 시험 `tests/room.rules.cjs` 20개 · 두 페이지 시험 `tests/room.browser.cjs`(같은 씨앗 · 시간표 어긋남 < 400ms · TV 막대 · 아이 r = tvs).
- 방 들어가기 · 방 열기 직전에 `version.json`을 다시 읽어, 앱이 새로 올라왔으면 '새로 고치기'(두 기기가 다른 판이면 시간표가 어긋남).
- 다음: 다른 고르기 칸(소3 · 가1 …)도 TVS로 · TV 결과 띠에서 별 · 번호 빼고 반 막대(X6 → 아래 v3).

## v3 — TV 결과 띠에서 번호 · 별 빼기(11-08 토론 X6 첫 커밋 · DB 0)
9살 눈 공격 채택: TV 띠에 '번호 + 별' 칩이 뜨면 반 전체 앞에 누가 아직 못 끝냈는지 · 누가 별이 적은지 드러난다.
- **TV 띠**(`screens/cell.js` drawStrip): 보기 · 연습 = "들어온 기기 m대" · 확인 게임 · 결과 = **"끝낸 아이 n / m" + 반 막대 하나 + "아직 k명"**(수만 · 누군지 X). m = 방 res 칸 수(들어온 기기) · n = 이 칸 · 이번 판 시작 뒤 결과를 보낸 기기(TVS 판 중간 답 글자는 n = 0이라 안 셈).
- **크게 보기**(띠를 누름 · allEl): 같은 규칙 + **별 분포**(별 셋 · 둘 · 하나 · 0 칸마다 몇 명). 1~3명인 칸은 수 대신 **'조금'**, 막대도 같은 짧은 토막(길이로 수를 읽지 않게). 0명은 '0명'.
- **복사**(선생님): 지금처럼 번호 · 짝꿍 · 별 · 맞힌 수(클립보드 — 화면에 비치지 않음). 단 클립보드가 막힌 기기에서는 글 상자 창이 떠서 TV에 비칠 수 있다(남은 걱정).
- **아이 기기**: 방에서 결과를 보냈으면 결과 카드 아래에 **"TV에 갔어요"** 한 줄(보내기 실패면 안 붙음 · 아래 띠는 "선생님을 기다려요"만).
- 서버 · DB 규칙 그대로. 다음(둘째 커밋): 갈래 막대(res.t = 단계 이름 · 틀린 수 3 이상) · 별 0 연속 알림(X11).
- 시험: `tests/room.browser.cjs` — TV 띠 '끝낸 아이 1 / 1' · 막대 100% · 번호 · 별 · 칩 0 · 크게 보기 번호 X · 별 분포 '조금|0명|0명|0명' · 아이 카드 'TV에 갔어요'.
