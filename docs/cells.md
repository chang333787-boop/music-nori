# 칸 모듈 약속 — `app/js/cells/<칸>.js` (견본: `so4.js` 높게·낮게)

칸 하나 = 파일 둘: `app/js/cells/<칸>.js` + `app/css/cells/<칸>.css`(비어 있어도 꼭 있어야 함 — 칸 화면이 불러옴). 칸 id·이름·먼저 필요한 칸·확인 게임 설명은 `engine/cells.js`가 정본.

```js
export default {
  show(ui, kit)   { … return 정리함수 },   // 보기
  follow(ui, kit) { … return 정리함수 },   // 따라 하기
  game(ui, kit)   { … return 정리함수 },   // 확인 게임
};
```

## ui (칸 화면이 줌) — 11-07 평가 2차로 '모든 칸이 같은 자리'를 쓰게 바뀜
- `ui.stage` — 무대 그릇(가로 약 1300 × 세로 약 400 · display:flex). 여기에 그린다
- 맨 위 한 줄(무대 안 맨 위) = `[문제 번호] 지시 글 …… [말풍선]`
  - `ui.say(글)` — 지시 한 줄(30px). **보기 · 연습 · 확인 게임 모두** 늘 한 줄 있어야 한다(게임 중에도 "높으면 나무, 낮으면 연못을 눌러요")
  - `ui.count(i, n)` — 문제 번호 "3 / 12"(맨 왼쪽 한 곳). 칸 안에 따로 번호 칩을 그리지 않는다
  - `ui.tell(글, kind, ms)` — 말풍선(맨 오른쪽 한 곳): 맞았는지("맞아요" good · "다시 들어 봐요" oops) · 박 세기("1" "2" "3" "4" count). **판정 말 · 박 세기 숫자를 무대 내용 위에 겹쳐 그리지 않는다**
- `ui.setBar(...단추)` — 아래 띠 가운데(높이 늘 그대로). 연습 · 게임에서는 '다시 듣기'나 큰 '톡'을 여기에. 고르기 답 단추는 여기 말고 오른쪽 답 묶음에
- `ui.practice(n)` — 연습 점("○○○ 3번 이어서 맞히면 게임")은 아래 띠 왼쪽에 칸 화면이 그림. 칸은 맞힐 때마다 `ui.practice(이어서 맞힌 수)`만 부른다(칸 안에 점을 따로 그리지 않음)
- 기본 아래 띠: 보기 = '연습해 볼래요' · 연습 · 확인 게임 = 비움. '넘어가기' · '다시 보기'는 머리띠 오른쪽(칸 화면이 그림)

## kit
- `engine`(소리) · `device` · `band`(low·mid·high — 박 판정 너그러움) · `cell` · `friend`(갈래 친구)
- `h` · `onPress`(누르는 순간 반응) · `friendImg(친구, 자세)` · `setPose(그림, 친구, 자세)` — 자세: idle · play · happy · oops(고슴도치만 jump 더)
- `next()` 다음 단계 · `pass(글)` 연습을 지남(→ '확인 게임' 단추) · `finish(결과)` 확인 게임 끝
- `ez(글)` — 1~2학년 판(`band === 'low'` · 판정 '넉넉하게')이면 쉬운 말 바꾸기 표(`engine/cells.js` easyText — 4분음표 → 따 · 2분음표 → 긴 따 · 박자표 → 묶음 표시 …)를 거친 글, 아니면 그대로. `ui.say` · `ui.tell` · `answers` 글 라벨 · 결과 카드 · 시작 카드는 칸 화면이 알아서 거치므로, **칸이 무대에 직접 그리는 글**(범례 · 예시 카드 · 까닭 한 줄)만 `kit.ez`로 감싼다. 표로 안 되는 말('박자' · '마디'처럼 칸마다 뜻이 다르거나 받침이 바뀌는 말)은 그 칸에서 `kit.band === 'low'`로 나눈다
- `answers(items, onPick)` — **고르기 답 단추 묶음(무대 오른쪽 세로 한 줄 · 흰 바탕 · 잉크 외곽선 · 왼쪽 그림 칩 · 28px 글)**. items = `[{ key, label, chip, locked }]` → `{ el, btn(k), lock(k, on), mark(k, 'right'|'wrong'), clear() }`. 게임 중 고를 것이 늘어나면 처음부터 다 깔고 `locked`로 잠가 둔다(자리가 밀리지 않게)
- `setAuto(fn)` — **자동 시험용 '지금 맞는 행동 하나'**. 단계마다 꼭 정한다(보기: 예시 하나씩 누르다 `next()` · 따라 하기: 맞는 답 · 확인 게임: 시작 단추 → 맞는 답 / 맞는 때 두드림). `tests/cells.browser.cjs`가 0.16초마다 부른다
- `sfx.good(engine)` · `sfx.oops(engine)` · `playSeq(engine, [{p, d, gap}], {inst})` → `{ starts, end, ac }` · `msUntil(ac, t)` · `timers()`(정리 때 한꺼번에 멈춤) · `rng(seed)` · `shuffle`
- `scoreChoices(맞음틀림[], 이어서n)` → `{ total, kept, streak, starOn, rules }`
- 박 판정이 필요하면 `engine/judge.js`(windows · judgeTaps)와 `app/js/clock.js`(audioToPerf)를 import — 징검다리(`screens/tap.js`)가 본보기

## finish(결과)
제목은 늘 **"N번 중 M번 맞혔어요"** 꼴(칸마다 다른 내용은 facts 둘째 줄에). 기준이 둘이면 이름을 붙임("높이 23개 다 맞힘 · 박자 맞춤 17개"). 결과 카드 옆 친구 그림은 칸 화면이 붙인다(칸이 따로 그리지 않음). `group`으로 다시 보기 묶음 크기.
`{ title: '12번 중 10번 맞혔어요', replay: [true, false, …], facts: ['가장 길게 이어서 6번'], starOn: [①, ②, ③], rules: ['절반 넘게 맞혔어요', '5번 이어서 맞혔어요', '모두 맞혔어요'], tip: '사실 한 줄' }`
- 별 셋은 기준 글과 함께. 받은 별만 채움. 칭찬은 기준을 넘었을 때만, 무엇을 잘했는지 사실로
- tip = 틀린 곳에서 찾은 사실("높이 차이가 작을 때 헷갈렸어요") — 빈 칭찬 X
- 같은 화면에서 결과 '한 번 더'로 다시 하면 결과 별 줄 끝에 앞 판에 받은 별을 점선 빈 별 + '아까'로(`resultCard` before · 칸 화면이 앞 판 starOn을 기억 · 화면을 떠나면 잊음 · 기기 기록끼리 견주지 않음 — X2)
- 칸 화면이 결과를 기기에 남긴다(`cellkit.saveResult` — 날짜 · 별 · 맞힌 수/전체(replay에서) · tip, 칸마다 최근 10개) → 선생님 칸 '이 기기 기록 보기'(#/records). 그래서 tip은 '틀린 갈래' 한 줄로 읽혀야 한다

## 한 칸이 도는 순서(계획서)
1. **보기** — 예시 카드에는 누를 수 있다는 표시(스피커 그림)와 묶음 위 "눌러서 들어 봐요" · 예시 여러 개(다른 악기 · 다른 높이/길이). 소리와 그림이 함께 · 기호는 소리와 함께 반짝
2. **연습**(예전 이름 '따라 하기') — 세 번 이어서 맞히면 `kit.pass()` · 못 해도 '넘어가기' · 틀리면 까닭이 보이는 피드백("두 번째 소리가 더 낮았어요") + 다시 듣기
3. **확인 게임** — 시작 카드(무엇을 하는지 한 줄 + 판 수) → 30~60초 · 소개 → 발전 → 비틀기 → 마무리 · 실수해도 끝까지 · 키보드도 됨

## 결과가 사실만 말하게 · 찍어서 별 받기 막기(11-08 토론 N1 · N2)
- **results 칸 셋**: `true` 맞음 · `false` 틀림 · `null` 고르기 전에 시간이 지남. 점수에서는 null도 틀림이지만 `scoreChoices`가 `late`로 따로 세고, 다시 보기 줄에서는 작은 점선 동그라미(`.l`), 기록(hist)에는 `l`로 남는다.
- **보이는 고르기 시계**: 시간이 있는 고르기 칸은 답이 열릴 때 `A.timer(초)` — 답 단추 묶음 아래 줄이 줄어든다(깜빡임 · 소리 · 숫자 X). 고르면 `A.timer(0)`. 다시 듣기는 시계를 다시 채운다(횟수 제한 X).
- **결과 한 줄(tip)**: 칸 파일이 `export function tipOf(plan, results, …)`로 떼어 내고 `kit.factTip(results, 갈래들, 완벽 글)`을 쓴다. 갈래 말은 그 갈래가 틀린 판(시간 지남 뺌)의 2/3를 넘고 3번 이상일 때만, 그 밖엔 "7 · 10번째 판을 틀렸어요" · 시간 지남은 따로 한 줄.
- **찍기 바닥**: 고르기 칸은 `kit.scoreChoices(results, 5, { chance: 판마다 찍어 맞힐 확률 })` — 별 ① = 찍어서는 10%도 안 나오는 수 이상(`minKeepP`), 별 ② = ①을 받은 뒤 이어서 n번. 문항 꼴을 아는 찍기(번갈아 누르기)가 더 잘 맞는 칸은 확률을 넉넉히(가1 `GUESS`). 박 칸은 chance 없이 예전 규칙.
- **단계 안 섞기 · 씨앗**: `kit.stageShuffle(PLAN, CUTS, kit.rng(kit.seed()), SHUF)` — 단계 경계는 그대로, 단계 안에서만 섞고 반쯤 뒤집음(같은 답 세 번 연속 X · 처음 네 판 ABAB X · 답 수 같게). 씨앗은 `kit.seed()`(시험 `?seed=N` > 방 아이 기기 = 방 · 칸 · 알림 시각 > 방이 열린 TV > 혼자). `kit.finish({ …, sd })`로 기록에 남겨 같은 판을 다시 만든다. 지금 소4 · 가1 — 나머지 다섯 칸은 다음 차례(문항 표로 통일).
- **두드림 어긋남 기록(X4)**: 박 칸은 `kit.finish({ …, t: tapStats(맞힌 두드림 어긋남들, 놓친 수, { lat, band, bpm }) })` — 기기 기록에만 남고 화면에는 안 나옴(`docs/measure.md` §6). 칸 화면이 기록에 `r`(solo · room · tvs)을 붙인다.
- **단계 안 섞기 · 씨앗**: `kit.stageShuffle(PLAN, CUTS, kit.rng(kit.seed()), SHUF)` — 단계 경계는 그대로, 단계 안에서만 섞고 반쯤 뒤집음(같은 답 세 번 연속 X · 처음 네 판 ABAB X · 답 수 같게). 씨앗은 `kit.seed()`(시험 `?seed=N` > 방 아이 기기 = 방 · 칸 · 알림 시각 > 방이 열린 TV > 혼자). `kit.finish({ …, sd })`로 기록에 남겨 같은 판을 다시 만든다. 고르기 칸 여덟(소3 · 소4 · 소5 · 셈1 · 가1 · 가2 · 가3 · 악2) 모두.

## 듣고 고르기 공용 틀 — `_pick.js` (11-14 · 소6 · 형1 · 화1 · 셈2)
소리 도막(하나 또는 둘)을 듣고 단추 둘(셋) 가운데 하나를 고르는 칸은 모양이 같다. 그래서 칸 파일은 **무엇을 들려주고 무엇이 답인가**(문항 표 · 도막 만들기 · 글)만 적고, 보기 · 연습 · 확인 게임 · TV 소리 모드 화면은 `app/js/cells/_pick.js`가 만든다(모양 `app/css/cells/_pick.css` — 처음 불릴 때 한 번 붙임). 같은 꼴의 새 칸(예: 긴 소리·짧은 소리 견주기)은 이 틀로 만든다.

- `pickCell(C)` → `{ mod, tvsSpec }`. 칸 파일 끝: `export const TVS = true; export const tvsSpec = cell.tvsSpec; export default cell.mod;`
- `C` = `{ friend, keys, label(key, lo), chip(key)?, lock?, rightOf(row), build(row, lo), names(row, lo), say: { show, follow, game, kid }, wrong(row, lo), note(lo)?, EX(lo), pool, passText, game: { title, sub }, PLAN, CUTS, SHUF, GUESS?, tipOf }`
  - `keys` = 답 키 차례(단추 차례 = 키보드 1 2 3) · `label` = 단추 글(lo = 1~2학년 판) · `chip` = 단추 그림(svg 글)
  - `build(row)` → 도막 `[{ lines: [음 줄, …], cap }]`. 도막이 둘이면 사이에 0.5초 쉼. 한 도막 안의 줄들은 같은 때에 함께 난다(화1 '함께'). **화면 · 소리 없이 표만 만들어야 한다**(node 시험이 부른다)
  - `line(가락, { inst, vel, shift, beat })` = `[[음 높이(없으면 쉼), 박 수], …]` → 음 줄 · `nearSegs(도막들)` = `NEAR`의 `play` · `instName(악기)` = 악기의 우리말 이름
  - `lock: { key, at, tell(lo) }` = 확인 게임에서 `at`번째 판부터 나타나는 단추(형1 '비슷한 가락' · 셈2 '그대로' — 연습에서는 처음부터 보임). 단추 수가 바뀌는 칸은 `GUESS`로 판마다 찍기 확률을 적는다
  - `note(lo)` = 보기 화면의 작은 알림(소6 '컴퓨터로 만든 악기 소리예요' · 셈2 '막대가 굵을수록 센 소리예요')

- **지킬 것**: 같은 꼴의 판은 답과 상관없이 소리 길이가 같다(답이 열리는 때로 새지 않게) · 같은 답이 세 번 이어지지 않는다 · 맞고 틀림은 귀로 가릴 수 있는 사실만 묻는다(화1은 '어울린다 · 안 어울린다'를 묻지 않음) · 틀렸을 때 글은 사실 한 줄(`wrong`).
