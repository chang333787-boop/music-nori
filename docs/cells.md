# 칸 모듈 약속 — `app/js/cells/<칸>.js` (견본: `so4.js` 높게·낮게)

칸 하나 = 파일 둘: `app/js/cells/<칸>.js` + `app/css/cells/<칸>.css`(비어 있어도 꼭 있어야 함 — 칸 화면이 불러옴). 칸 id·이름·먼저 필요한 칸·확인 게임 설명은 `engine/cells.js`가 정본.

```js
export default {
  show(ui, kit)   { … return 정리함수 },   // 보기
  follow(ui, kit) { … return 정리함수 },   // 따라 하기
  game(ui, kit)   { … return 정리함수 },   // 확인 게임
};
```

## ui (칸 화면이 줌) — 11-07 평가 2차로 '모든 칸이 같은 자리'를 쓰게 바뀜
- `ui.stage` — 무대 그릇(가로 약 1300 × 세로 약 400 · display:flex). 여기에 그린다
- 맨 위 한 줄(무대 안 맨 위) = `[문제 번호] 지시 글 …… [말풍선]`
  - `ui.say(글)` — 지시 한 줄(30px). **보기 · 연습 · 확인 게임 모두** 늘 한 줄 있어야 한다(게임 중에도 "높으면 나무, 낮으면 연못을 눌러요")
  - `ui.count(i, n)` — 문제 번호 "3 / 12"(맨 왼쪽 한 곳). 칸 안에 따로 번호 칩을 그리지 않는다
  - `ui.tell(글, kind, ms)` — 말풍선(맨 오른쪽 한 곳): 맞았는지("맞아요" good · "다시 들어 봐요" oops) · 박 세기("1" "2" "3" "4" count). **판정 말 · 박 세기 숫자를 무대 내용 위에 겹쳐 그리지 않는다**
- `ui.setBar(...단추)` — 아래 띠 가운데(높이 늘 그대로). 연습 · 게임에서는 '다시 듣기'나 큰 '톡'을 여기에. 고르기 답 단추는 여기 말고 오른쪽 답 묶음에
- `ui.practice(n)` — 연습 점("○○○ 3번 이어서 맞히면 게임")은 아래 띠 왼쪽에 칸 화면이 그림. 칸은 맞힐 때마다 `ui.practice(이어서 맞힌 수)`만 부른다(칸 안에 점을 따로 그리지 않음)
- 기본 아래 띠: 보기 = '연습해 볼래요' · 연습 · 확인 게임 = 비움. '넘어가기' · '다시 보기'는 머리띠 오른쪽(칸 화면이 그림)

## kit
- `engine`(소리) · `device` · `band`(low·mid·high — 박 판정 너그러움) · `cell` · `friend`(갈래 친구)
- `h` · `onPress`(누르는 순간 반응) · `friendImg(친구, 자세)` · `setPose(그림, 친구, 자세)` — 자세: idle · play · happy · oops(고슴도치만 jump 더)
- `next()` 다음 단계 · `pass(글)` 연습을 지남(→ '확인 게임' 단추) · `finish(결과)` 확인 게임 끝
- `answers(items, onPick)` — **고르기 답 단추 묶음(무대 오른쪽 세로 한 줄 · 흰 바탕 · 잉크 외곽선 · 왼쪽 그림 칩 · 28px 글)**. items = `[{ key, label, chip, locked }]` → `{ el, btn(k), lock(k, on), mark(k, 'right'|'wrong'), clear() }`. 게임 중 고를 것이 늘어나면 처음부터 다 깔고 `locked`로 잠가 둔다(자리가 밀리지 않게)
- `setAuto(fn)` — **자동 시험용 '지금 맞는 행동 하나'**. 단계마다 꼭 정한다(보기: 예시 하나씩 누르다 `next()` · 따라 하기: 맞는 답 · 확인 게임: 시작 단추 → 맞는 답 / 맞는 때 두드림). `tests/cells.browser.cjs`가 0.16초마다 부른다
- `sfx.good(engine)` · `sfx.oops(engine)` · `playSeq(engine, [{p, d, gap}], {inst})` → `{ starts, end, ac }` · `msUntil(ac, t)` · `timers()`(정리 때 한꺼번에 멈춤) · `rng(seed)` · `shuffle`
- `scoreChoices(맞음틀림[], 이어서n)` → `{ total, kept, streak, starOn, rules }`
- 박 판정이 필요하면 `engine/judge.js`(windows · judgeTaps)와 `app/js/clock.js`(audioToPerf)를 import — 징검다리(`screens/tap.js`)가 본보기

## finish(결과)
제목은 늘 **"N번 중 M번 맞혔어요"** 꼴(칸마다 다른 내용은 facts 둘째 줄에). 기준이 둘이면 이름을 붙임("높이 23개 다 맞힘 · 박자 맞춤 17개"). 결과 카드 옆 친구 그림은 칸 화면이 붙인다(칸이 따로 그리지 않음). `group`으로 다시 보기 묶음 크기.
`{ title: '12번 중 10번 맞혔어요', replay: [true, false, …], facts: ['가장 길게 이어서 6번'], starOn: [①, ②, ③], rules: ['절반 넘게 맞혔어요', '5번 이어서 맞혔어요', '모두 맞혔어요'], tip: '사실 한 줄' }`
- 별 셋은 기준 글과 함께. 받은 별만 채움. 칭찬은 기준을 넘었을 때만, 무엇을 잘했는지 사실로
- tip = 틀린 곳에서 찾은 사실("높이 차이가 작을 때 헷갈렸어요") — 빈 칭찬 X

## 한 칸이 도는 순서(계획서)
1. **보기** — 예시 카드에는 누를 수 있다는 표시(스피커 그림)와 묶음 위 "눌러서 들어 봐요" · 예시 여러 개(다른 악기 · 다른 높이/길이). 소리와 그림이 함께 · 기호는 소리와 함께 반짝
2. **연습**(예전 이름 '따라 하기') — 세 번 이어서 맞히면 `kit.pass()` · 못 해도 '넘어가기' · 틀리면 까닭이 보이는 피드백("두 번째 소리가 더 낮았어요") + 다시 듣기
3. **확인 게임** — 시작 카드(무엇을 하는지 한 줄 + 판 수) → 30~60초 · 소개 → 발전 → 비틀기 → 마무리 · 실수해도 끝까지 · 키보드도 됨
