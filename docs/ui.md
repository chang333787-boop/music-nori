## 크기
- 글자 단계 48 / 32 / 24 / 20 / 18 — 아이가 보는 글은 18px 아래로 X
- 단추: 3px 잉크 외곽선 · 모서리 18 · 가장 작은 것 64px · 주요 단추는 아래 6px 턱 · 누르면 60ms에 내려가고 120ms에 올라옴(튕김 X)
- 크롬북 1366×768 가로에서 스크롤 0

## 흐름
- 아이 화면에 **만드는 중 · 선생님 상태 글 X**(가제목 · 0단계 · '지연 맞추기 안 함'). 선생님 도구는 머리띠 오른쪽 톱니 안(맞추기가 안 됐으면 톱니에 주황 점만)
- 한 화면에 할 일 하나. 처음 화면은 추천 놀이 카드 하나만 크게 + 주황 '시작' 꼬리표
- 놀이 화면: 시작 전(가운데 카드 + 아래 '시작' 하나) → 노는 중('시작' 자리에 그대로 '톡!' · 멈춤은 무대 오른쪽 위 · 설정 숨김) → 끝(캐릭터가 도착한 뒤 결과 카드 · 아래 '다시' + '다음 단계')
- **신호 · 판정 · 캐릭터는 한 자리에**(리듬게임 관례) — 다음 돌의 줄어드는 고리 · 머리 위 판정 말
- 결과는 사실로: "24번 중 22번 맞았어요" · 돌 줄 다시 보기 · 별마다 기준 글(① 절반 넘게 ② 8번 이어서 ③ 모두) · 사실 한 줄("놓친 박: 10째, 16째")
- 칭찬은 기준을 넘었을 때만, 무엇을 잘했는지 구체적으로. 빈 칭찬 X
- 악보 판(`#/lab`): 맞다 · 틀리다가 없다 — 기호를 고르고 악보의 자리를 눌러 넣고, 한 번 더 눌러 뺀다. 바뀐 마디가 바로 들리고, 주황은 [듣기] 하나. 아래 한 줄은 그 기호가 하는 일만 사실로 적는다(`docs/flow.md` 4장)
- 찾아 쓰기(`#/find`)는 선생님 화면이지만 글자 18px · 주황 하나 규칙을 그대로 지킨다. 화면은 스크롤 0이고, 긴 흐름 표와 담은 목록은 칸 안에서만 넘긴다. 주황은 [목록 복사] 하나
- 처음 화면 아래 줄은 카드 여섯(악보 판을 더함) · 선생님 칸은 카드 여덟 두 줄(출처와 저작권은 머리띠 오른쪽 글 단추로 옮김)

## 하지 말 것
1. 만드는 중 · 선생님용 글을 아이 화면에
2. 놀이 중에 다시 · 빠르기 · 설정을 누를 수 있게
3. 박 신호를 손과 눈이 가는 곳과 떨어뜨리기
4. 결과와 안 맞는 칭찬 · 기준 없는 별
5. 기능마다 아이콘 · 색을 새로 고르기(＋ · 시계 · 이모지) — 아이콘 자리는 친구 얼굴
