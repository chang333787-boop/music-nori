# 지금 목표 (11-07 교사 "목표를 정해서 진행해, 멈추지 말고")

## 목표 — 첫 판 13칸 놀이판
아이가 **처음 화면 → 추천 칸 → 보기 → 따라 하기 → 확인 게임 → 결과**를 13칸 모두 끝까지 할 수 있다. 마을 지도에서 아무 칸이나 고를 수 있고(잠금 없음 · 추천 다음 칸만 크게), 코덱스 그림이 들어가 있다.

## 다 됐다고 말할 수 있는 기준
1. 13칸(소3 · 소4 · 소5 · 가1 · 가2 · 가3 · 리1 · 리2 · 리4 · 리5 · 리6 · 악1 · 악2)마다
   - 보기: 예시 여러 개(다른 악기 · 다른 높이) · 소리와 그림이 함께
   - 따라 하기: 세 번 맞히면 통과 · 못 해도 넘어갈 수 있음 · 틀리면 까닭이 보이는 피드백
   - 확인 게임: 30~60초 · 소개 → 발전 → 비틀기 → 마무리 · 별 셋(기준 글) · 사실 한 줄
2. 마을 지도: 갈래 넷(소리 · 가락 · 박·리듬 · 악보) · 칸마다 별 · 추천 다음 칸 · 앞 칸을 건너뛰면 한 줄 안내와 바로 가기
3. 기기에 진행 저장 · 처음 화면에 '다음 칸' 카드
4. 코덱스 그림(음악대 다섯 × 자세 · 배경 · 징검돌 · 얼굴)
5. 자동 시험: `npm test` · `npm run test:browser`(13칸 모두 자동으로 끝까지 · 스크롤 0 · 콘솔 오류 0) 통과
6. 처음 보는 눈 평가 한 번 더 → 고침 → GitHub Pages에 올림
