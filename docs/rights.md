# 곡 권리 — 넣는 규칙 · 더하는 차례 · 지금 21곡

이 앱에 든 곡은 모두 **공개돼도 문제없는 가락**만이다. 근거는 곡마다 `engine/songs/ledger.js`(곡 권리 대장)에 한 줄씩 있고, `node tests/songs.test.mjs`가 대장과 곡이 맞는지 늘 검사한다. 법률 자문이 아니다 — 정본 조사는 `음악앱-기획/research/songs.md`(166곡 판정)·`copyright.md`.

확인일 2026-11-07 · 11-08 판본 대조 전 9곡 내림(아래 3절 '대장에만 있는 곡').

## 1. 곡 넣는 규칙

1. **곡을 조각으로 나눠 따로 판정한다** — 가락(작곡) · 노랫말(작사) · 번안 가사 · 악보 판본 · 반주. 하나라도 '불가'면 그 조각은 뺀다.
2. **가락**: 작곡자가 1962년 이전에 사망했거나, 오래 구전된 전래·민요(작자 없음)일 때만. **사망 연도를 모르면 넣지 않는다.**
3. **미국 기준**(서버 = GitHub Pages): 1930년까지 공표된 곡만 미국에서도 만료로 본다. 1931년 이후 공표곡은 넣지 않는다(예: 피터와 늑대 1936).
4. **노랫말**: 이번 판은 넣지 않는다(계이름·음만). **한국어 번안 가사는 절대 넣지 않는다.** 곡 제목도 번안 제목(번안자 것) 대신 원어 제목이나 사실 그대로의 설명으로.
5. **판본**: 교과서·악보집·인터넷 편곡을 베끼지 않는다. 옛 출처 둘 이상을 대조해 **공통 원형만** 적고 대조한 출처를 기록한다. 대조를 실제로 못 했으면 `checked: false`로 솔직히 두고, **그 곡은 앱에 넣지 않는다**(대장 줄만 · `tests/songs.test.mjs`가 실패로 막음). 같은 표기를 옮겨 쓴 위키 판끼리는 독립 출처로 치지 않는다.
6. **반주**: 남의 편곡을 쓰지 않는다. 앱이 관용 화성(I·IV·V)으로 직접 붙인다.
7. **애매하면 뺀다**(상담해서 살리지 않는다 — 교사 결정). 화면에서 거르지 않고 `engine/songs/index.js`에서 가락째 뺀다(Pages가 저장소 파일을 그대로 내보내므로).
8. **새로 지은 단계 곡(자작)**: 뼈대(쓰는 음·마디 수·리듬)는 계획서 칸 표에서 온다. 유명 동요·교과서 곡 첫머리와 닮지 않아야 한다(아래 닮음 검사). 솔미솔미·도레미 같은 짧은 관용 음형은 괜찮다. 대장에 '교사 확인 전'으로 적고, 교사가 들어 본 뒤 고친다.
9. 원조에서 조를 옮기거나 앞부분만 쓴 곡은 대장 note에 적는다(저작인격권 — '다장조로 옮김'·'앞 도막만').

### 닮음 검사(`tools/simcheck.mjs`)

- 비교 단위는 **음 다섯 개짜리 조각**: 이웃한 음 사이 네 칸의 '음정(반음 차) + 길이 비율'(쉼표도 한 칸). 조나 빠르기를 바꿔도 같은 조각으로 센다.
- 겹침 비율 = 자작 곡의 조각 가운데 상대 곡에도 있는 조각의 몫. **40% 이상이면 다시 짓는다.**
- 상대 = 유명 곡 첫머리 20곡(학교 종·산토끼·곰 세 마리·송아지·반달·나비야·비행기·작은 별·생일 축하·퐁당퐁당·아기 상어·도레미 송·에델바이스·징글벨·코다이식 솔미 외침 등) + 앱의 외국 전래·클래식 곡 전부.
- 유명 곡 첫머리는 **저장소에 음으로 두지 않는다** — 조각의 해시만 `tools/simcheck.hashes.json`에. 원본은 저장소 밖 비공개 파일에서 `node tools/simcheck.mjs --build <파일>`로 해시를 만든다. 첫머리는 기억으로 적은 근사값이라 판정 보조일 뿐이다.
- 함께 찍는 '음정만' 겹침은 참고다. 솔·미 두 음 곡은 음정 종류가 둘뿐이라 이 값이 늘 높게 나온다(관용 음형).
- 시험에 역시험이 있다 — 앱 곡과 트윙클 첫머리를 자작이라고 넣으면 잡아내는지 본다.

## 2. 곡 하나 더하는 차례

1. **대장 줄 먼저** — `engine/songs/ledger.js`에 한 줄: 갈래(kind), 가락(누가·사망 연도·공표 연도·판정·까닭·미국 기준), 노랫말(`안 씀`), 판본(출처 둘 이상·대조 여부·note) 또는 자작이면 `made`(뼈대·지은 이·닮음 검사 결과).
   - 판정이 '가능'이 아니거나 미국 기준이 '가능'이 아니면 여기서 멈춘다(대장에만 남긴다).
   - 옛 곡(외국 전래 · 클래식 · 국내 전래)은 판본 대조(`edition.checked: true`) 전이면 대장 줄만 두고 곡에는 넣지 않는다.
2. **곡** — `engine/songs/index.js`에 `{ id, title, meter, tempo, key: 0, mel, cells, use }`. 적는 법은 `engine/song.js` 맨 위 주석. 높낮이 칸(소·가)에 쓰는 곡은 C4~E5 안.
3. **자작이면 닮음 검사** — `node tools/simcheck.mjs` → 대장 `made.simcheck`에 결과를 적는다.
4. **시험** — `node tests/songs.test.mjs`가 통과해야 한다(지금은 곡 수 21과 갈래 구성 12 · 7 · 2를 검사하므로 곡 수를 바꾸면 시험의 숫자도 같이). 선생님 칸의 곡 수 글은 `SONGS.length`로 저절로 맞는다.
