# 음악 놀이터 (가제목 · music-nori)

초등 1~6학년이 음악 개념을 **예시로 분명히 배운 뒤**, 그 요소(계이름 · 음 길이 · 박자표 · 셈여림 · 빠르기 …)를 곡에 직접 넣고 바꿔 보며 '아, 이럴 땐 이렇구나'를 스스로 찾는 놀이 앱. 무엇을 바꾸든 소리 · 악보 · 장면이 그 자리에서 함께 바뀐다. 캐릭터는 동물 친구 음악대.

- 지금: **첫 판 21칸 놀이판**(목표 [docs/goal.md](docs/goal.md)) — 처음 화면 → 추천 칸 → 보기 → 따라 하기 → 확인 게임 → 결과. 우리 반 시범 2027년 3월.
- 11-14: 기호를 악보에 넣었다 빼며 듣는 **악보 판**, 선생님이 찾는 말로 골라 쓰는 **찾아 쓰기**, 그 밑의 **요소별 공부 흐름** — [docs/flow.md](docs/flow.md)
- 11-14 둘째: 음색 · 형식 · 화음의 **첫 칸 셋**(소6 같은 악기·다른 악기 · 형1 같은 가락·다른 가락 · 화1 하나씩·함께)과 **계열 · 난이도 분석** — 단계마다 아이가 한꺼번에 해내야 하는 일을 따져 가벼운 것부터 차례를 권함. 앱이 스스로 따져 본 것이고 연구나 아이 자료로 확인한 것이 아니다([docs/flow.md](docs/flow.md) 8장)
- 계획서(근거 · 저작권 · 단계 설계): Claude 문서 「음악 개념 놀이 앱 — 구현 계획서」 · 요약은 [docs/plan.md](docs/plan.md)
- 앱 이름과 음악대 이름은 아직 정하지 않았다(가제목).

## 폴더
| 폴더 | 하는 일 |
|---|---|
| `engine/` | 화면 · 소리 없는 계산(node로 시험) — `theory.js` 음 이름 · 음계 · 화음 · 틱(4분음표 = 12틱) · `song.js` 곡 적는 법과 마디 검사 · `measure.js` 마디 채우기 · 분수 보기 · `judge.js` 박 판정 창 · 이어 지킨 박 · 지연 재기 · `songs/` 곡 권리 대장과 곡 · `marks.js` 악보 판의 기호 29개와 소리로 옮기는 규칙 · `flow.js` 요소별 공부 흐름(요소 10 · 단계 62 · 근거 꼬리표 · 찾기) · `load.js` 계열 · 난이도(단계마다 여섯 가지 — 귀 · 기억 · 기호 · 몸 · 낱말 · 한꺼번에 — 를 세어 난이도 1 ~ 5 · 앱 자체 분석) |
| `app/` | 화면 — `audio.js` Web Audio 합성(소리 파일 0개) · `notation.js` 오선 SVG · `band.js` 음악대(그림 `img/band/` · 코덱스 일러스트) · `screens/` 처음 · 마을 지도 · 칸 화면 · 징검다리 · 놀이터(`docs/playground.md`) · 악보 판(기호를 넣었다 빼며 듣기) · 곡 듣기 · 선생님 칸(지연 맞추기 · 스피커 점검 · 시작 칸 · 찾아 쓰기 · 출처) · `cells/` 개념 칸 21(약속 [docs/cells.md](docs/cells.md) · 듣고 고르기 공용 틀 `_pick.js`) |
| `tests/` | `npm test`(엔진 · 칸 지도 · 듣고 고르기 칸 · 박 칸 판정 · 곡 대장 · 악보 판 규칙 · 공부 흐름 · 계열 · 난이도 · 문서 표가 자료와 같은지) · `npm run test:browser`(화면 · 21칸 자동으로 끝까지 · 악보 판 · 찾아 쓰기 · 합성음 높이 ±6센트) |
| `docs/` | 목표(`goal.md`) · 계획 요약(`plan.md`) · 화면 약속(`ui.md`) · 칸 약속(`cells.md`) · 곡 넣는 규칙(`rights.md`) · 기기 측정(`measure.md`) · 요소별 공부 흐름 · 악보 판 · 찾아 쓰기와 그 근거(`flow.md` — 표는 `node tools/flowdoc.mjs`가 자료에서 뽑음) |

우리반RPG 음악실(같은 저자)의 소리 합성 · 오선 · 리코더 운지 · 이론 코드를 옮겨 다듬었다. 출처는 앱의 '출처' 화면과 각 파일 머리에 적었다.

## 곡과 저작권
작곡 · 작사 · 편곡한 사람이 모두 1962년 이전에 세상을 떠났거나, 오래 구전된 전래 가락이거나, 이 앱이 새로 지은 곡만 넣는다. 서버가 미국에 있어 1930년까지 공표된 곡만 넣는다. 노랫말은 아직 넣지 않는다. 곡마다 판정은 `engine/songs/ledger.js`(대장에 없는 곡은 시험이 막는다). 교과서 곡은 앱에 넣지 않는다.

교육과정 대응은 2022 개정 음악과 · 즐거운 생활과 성취기준을 기준으로 하며, 칸 이름과 차례는 이 앱이 붙인 것이다(특정 출판사 교과서 · 지도서와 무관).
