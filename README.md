# 음악 놀이터 (가제목 · music-nori)

초등 1~6학년이 음악 개념을 **예시로 분명히 배운 뒤**, 그 요소(계이름 · 음 길이 · 박자표 · 셈여림 · 빠르기 …)를 곡에 직접 넣고 바꿔 보며 '아, 이럴 땐 이렇구나'를 스스로 찾는 놀이 앱. 무엇을 바꾸든 소리 · 악보 · 장면이 그 자리에서 함께 바뀐다. 캐릭터는 동물 친구 음악대.

- 지금: **0단계(기반)** — 2026년 11~12월. 첫 판(13칸)은 2027년 1~2월, 우리 반 시범 3월.
- 계획서(근거 · 저작권 · 단계 설계): Claude 문서 「음악 개념 놀이 앱 — 구현 계획서」 · 요약은 [docs/plan.md](docs/plan.md)
- 앱 이름과 음악대 이름은 아직 정하지 않았다(가제목).

## 폴더
| 폴더 | 하는 일 |
|---|---|
| `engine/` | 화면 · 소리 없는 계산(node로 시험) — `theory.js` 음 이름 · 음계 · 화음 · 틱(4분음표 = 12틱) · `song.js` 곡 적는 법과 마디 검사 · `measure.js` 마디 채우기 · 분수 보기 · `judge.js` 박 판정 창 · 이어 지킨 박 · 지연 재기 · `songs/` 곡 권리 대장과 곡 |
| `app/` | 화면 — `audio.js` Web Audio 합성(소리 파일 0개) · `notation.js` 오선 SVG · `band.js` 음악대 그림 · `screens/` 처음 · 징검다리 박 놀이 · 곡 보기 · 지연 맞추기 · 스피커 점검 · 출처 |
| `tests/` | `npm test`(엔진 · 곡 대장) · `npm run test:browser`(화면 · 합성음 높이 ±6센트) |
| `docs/` | 계획 요약 · 곡 넣는 규칙(`rights.md`) · 기기 측정(`measure.md`) |

우리반RPG 음악실(같은 저자)의 소리 합성 · 오선 · 리코더 운지 · 이론 코드를 옮겨 다듬었다. 출처는 앱의 '출처' 화면과 각 파일 머리에 적었다.

## 곡과 저작권
작곡 · 작사 · 편곡한 사람이 모두 1962년 이전에 세상을 떠났거나, 오래 구전된 전래 가락이거나, 이 앱이 새로 지은 곡만 넣는다. 서버가 미국에 있어 1930년까지 공표된 곡만 넣는다. 노랫말은 아직 넣지 않는다. 곡마다 판정은 `engine/songs/ledger.js`(대장에 없는 곡은 시험이 막는다). 교과서 곡은 앱에 넣지 않는다.

교육과정 대응은 2022 개정 음악과 · 즐거운 생활과 성취기준을 기준으로 하며, 칸 이름과 차례는 이 앱이 붙인 것이다(특정 출판사 교과서 · 지도서와 무관).
